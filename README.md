# 🌾 Rice Crop Production Prediction

## 📌 Project Overview

Rice Crop Production Prediction is a Machine Learning project that predicts paddy yield based on the cultivated land area (Hectares).

The project uses a trained Machine Learning model to estimate rice production and provides a simple web interface for users.

## 🎯 Objectives

- Predict paddy yield using Machine Learning.
- Analyze the relationship between cultivated area and rice production.
- Build a user-friendly prediction application.
- Deploy the project using Streamlit, Render, and Vercel.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- FastAPI
- HTML
- CSS
- Git & GitHub

## 🤖 Machine Learning Models

The project explores the following regression algorithms:

1. Simple Linear Regression
2. Multiple Linear Regression
3. Ridge Regression
4. Lasso Regression
